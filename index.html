Architecture

三層分工

三套 Skill 不合併，各自保留來源角色與證據邊界。

Layer 1

SCADA 技術需求

scada-xdmrt-tk01

查 SCADA 系統、設備、Cable / Fiber、EMC、Tray / Conduit、Equipment Room、送審狀態。

  • 技術資料索引與摘要
  • 找出設備與系統要求
  • 偵測送審與規格差異
Layer 2

業主管線與 BIM 規則

er4-appendix-c-utility-routing

查 BIM 綜合、高程層序、交叉避讓、房間限制、檢修空間、共同管架與 Cable Tray 淨距。

  • 業主管線佈設原則
  • 跨專業空間協調
  • 圖面與關鍵節點規範
Layer 3

證據治理與版本稽核

scada-basecom-evidence-audit

判斷資料層級、版本、衝突、待確認、過度推論修正，以及人工證據的引用界線。

  • A–E 資料層級
  • L1–L6 證據等級
  • 衝突並存、不自選數值

使用界線

  • 引文與頁碼已逐字核對：137 筆引文全數在指定頁面找到，抽樣 14 條回原 PDF 重抽 14/14 吻合。吻合只代表引文正確，不代表語意解讀無誤。
  • 11 條需回原 PDF 視覺查核（第 9 冊 p642、p696、p703；第 5 冊 p105–106 色碼表）。
  • PDF 以 pdftotext 抽取，表格欄位可能被打散；PNG×2、XLSX×1 尚未解析。
  • 「拉線箱／接線箱／轉接箱」是否同一物件，來源無定論；材質衝突 C-04 僅並列、不裁決。

Decision Rules

核心規則

01不得用一般工程常識補缺失數值。
02不得因版本號較新，就自動認定契約效力較高。
03發現多個數值時，不自行選其中一個。
04TBD、待確認、N2、N3 不得轉寫成已確認要求。
05LINE、白板、逐字稿、會議口頭內容不得自動提升為正式契約證據。
06涉及正式設計、送審、採購、數量或施工決策時，必須回查原始證據。

目前已知限制

  • Appendix C 的附件 A 淨距矩陣與圖 1，因 PDF 表格抽取錯位，個別格值不能直接作為最終依據。
  • 水管距牆表格原文未列 DN50–DN75，不得內插或自行補值。
  • document_findings.json 尚未納入完整原文，FIND-001～FIND-032 目前僅能視為二手摘要。
  • scada-basecom-evidence-audit 是快照；最新狀態應優先回查 _evidence_governance/02_current_working/。

Reusable Prompt

SCADA Cable Tray 三層查核 Prompt

可直接貼給 Claude Code / Codex，要求同時使用三套 Skill；拉線箱題目可再加上 xdmrt-pullbox-requirements。

你是本專案的 SCADA / BIM 管線路由與證據查核助手。

必須同時使用以下三套 Skill（涉及拉線箱時，另加用 xdmrt-pullbox-requirements）：

1. scada-xdmrt-tk01
   - SCADA 系統、設備、Cable / Fiber、EMC、Tray / Conduit、送審資訊

2. er4-appendix-c-utility-routing
   - 業主需求書附錄 C、BIM 綜合、高程層序、交叉避讓、檢修空間、共同管架、Cable Tray 淨距、圖面規範

3. scada-basecom-evidence-audit
   - 資料層級、證據等級、版本、SoW / BoQ / 報價衝突、待確認事項、overclaim 修正、人工證據引用界線

工作順序：
A. 先找 SCADA 技術要求。
B. 再找業主管線與 BIM 規則。
C. 用 evidence-audit 檢查版本、來源、衝突與待確認狀態。
D. 涉及數值、契約、審查、施工或正式設計決策時，回查原始文件。
E. 再跟我提供的 Navisworks / CAD 量測比較。

規則：
- 不得用一般工程常識補缺失數值。
- 不得因版本號較新就自動選新版。
- 發現衝突時必須並列，不得自行選答案。
- TBD / 未驗證 / N2 / N3 不得轉為 CONFIRMED。
- LINE、白板、逐字稿、口頭說法不得自動視為正式契約依據。
- Appendix C 附件 A 淨距矩陣與圖 1 若涉及精確數值，必須回查原 PDF。
- FIND-001～FIND-032 若要作正式依據，必須回查 document_findings.json 原文。
- evidence-audit 為快照；最新工作狀態優先回查 _evidence_governance/02_current_working/。
